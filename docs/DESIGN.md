# 科迹 SciTrail 设计系统（DESIGN.md）

> 本文件是界面工作的**单一规则来源**，写给人类协作者与 AI 编码智能体：在新增或修改任何 UI 之前，先遵守本文件，再发明新的视觉规则。数值（颜色、字号、圆角）的唯一来源是 [`src/styles/tokens.css`](../src/styles/tokens.css)，本文不复制具体数值，只定义规则与用途。违反本文件的代码按**缺陷**处理，不是风格偏好。

---

## 1. 产品性格

极简清单风（Things / Todoist 血统）。界面应当**克制、高密度、工具感**（calm, dense, operational），为以下场景设计：

- 每天多次、每次长时间的日常工具
- 信息密度优先于装饰
- 键盘驱动的工作流（数字键切页、全局速录、Esc 关闭）
- 明暗双主题（跟随系统）

**避免**：营销式大留白、装饰性渐变、大面积品牌色填充、模糊的层次关系（背景/卡片/弹层必须有明确分层）。

## 2. 排版刻度（铁律）

组件必须使用刻度令牌 `var(--text-2xs|xs|sm|md|base|lg|xl|2xl)`，用途定义见 tokens.css 注释。

- **禁止**出现 `font-size: 13px` 这类任意值，或 Tailwind 式 `text-[13px]`。
- 正文默认继承 body 的 `--text-base`；列表/账本行用 `--text-md`；徽章 chip 用 `--text-xs`。
- 唯一例外：**SVG 属性内的数字字号**（`<text font-size="10">`，图表坐标轴等）不受刻度约束——SVG 表现属性不支持 CSS 变量。
- 数字变化或对齐的场景（倒计时、金额、日期）必须加 `font-variant-numeric: tabular-nums`。

## 3. 色彩语义（铁律）

颜色表达语义，不表达个性。语义色全项目一致：

| 语义 | 变量 | 允许的场景 |
|---|---|---|
| 危险/逾期/!高/该催了 | `--danger` | 逾期徽章、!高优先级、删除确认态、"该催了"、destructive 按钮 |
| 警告/将到期/垫付中 | `--warn` | 7 天内倒计时、垫付未回款、!中优先级 |
| 成功/完成/达标 | `--ok` | 完成、达标 ✓、成功消息、连续天数 |
| 交互/选中/链接 | `--accent` | 主按钮、选中行、链接、焦点边框 |
| 课题色 | project.color | **仅**小色点（7–10px 圆点）与 chip 底色（`color-mix` ≤14% 透明度），禁止大面积使用 |

- 一切 CSS 颜色必须走令牌（`light-dark()` 双值），**禁止硬编码**十六进制/白/黑。
- 合法例外：TS 常量中的类型色映射（`KIND_META`、`STAGE_COLORS`、`KIND_COLORS`——用于行内 `:style` 与 SVG `stroke`/`fill` 属性，属性值无法引用 CSS 变量）。
- 红色是稀缺资源：一个视图内红色元素超过三处，说明层级失败。

## 4. 布局与组件规则

- 侧栏固定 `--sidebar-w`（200px）。**一级导航 11 项封顶**（现有：今日/任务/轨迹/课题/DDL/论文/成果/台账/周报/回顾/设置）——新功能必须并入现有页面或做二级入口，不得新增侧栏项。
- 页面内容区 `max-width: 980px`（数据密集页 `wide` 1080px），内边距 18/24。
- 抽屉：右侧固定 320–380px + 半透明遮罩（`rgba(0,0,0,.3)`），头部标题/关闭、底部操作区、中部滚动。
- 徽章/chip：高度 ≤20px，圆角 7–10px，底色用语义色 `color-mix` 12–14% 透明度。
- 表单控件：输入/选择统一 `padding: 7px 9px; border-radius: 7px`，聚焦边框 `--accent`。
- 列表行：hover 背景 `--hover`；点击行打开抽屉；完成态用删除线 + muted，不另配色。
- 圆角统一 `--radius`（10px），卡片嵌套时内层递减至 7px。

## 5. 交互惯例

- 破坏性操作**两段式确认**：按钮先变"确认删除？"再执行（不用系统 confirm 的场景）。
- 状态可在列表内**直接流转**（select 内联），不必进编辑抽屉。
- 键盘：`1–9/0/e` 切页（输入框聚焦时不抢键）、`Esc` 关抽屉/弹层、`Ctrl+Alt+K` 全局速录、`Enter` 提交。
- 空状态必须给下一步指引（"到 XX 页新建一个"），不留白板。
- 错误消息用可读中文说明补救方式，不裸露错误码。

## 6. 性能红线

- 轨迹账本条目 > 2000 时**必须**引入虚拟滚动（Codex App 2026-09 卡顿事故的教训）。
- 热力图/趋势图为手写 SVG，单页 DOM 节点 < 3000。

## 7. 变更流程

- 改数值 → 只改 `tokens.css`，全项目生效。
- 新组件 → 先查本文件第 4 节找同类规则；确需新规则，先更新本文件再写代码。
- 提交前自检：`grep -rE "font-size:\s*\d+px" src/` 必须为空（SVG 属性除外）；`grep -rE "#[0-9a-fA-F]{3,6}" src/ --include="*.vue"` 中出现的硬编码色需逐一说明理由。

## 8. 品牌与图标

- 图形语义：**S 形蜿蜒轨迹**（SciTrail 首字母 + "科迹"本义）· 两个**实心足迹点** = 已走的里程碑 · 终点**目标环** = 直达但未抵达的目标（毕业要求）。整体气质与第 1 节产品性格一致：冷静、克制、有方向。
- 色彩：主蓝即 `--accent #4a7fd6`，图标底板用对角微渐变 `#4f86dc → #33619f`（同族加深，不引入新色相）；轨迹与足迹点为纯白。
- 源文件：`docs/design/icon.svg`（1024 母版）、`logo-light.svg` / `logo-dark.svg`（横幅明暗双版）。改图标**必须**改 SVG 源文件后重新 `pnpm tauri icon <png>`，禁止直接编辑 `src-tauri/icons/` 下的产物。
- 圆角方形四角透明，浅色/深色背景通用；应用内若需小尺寸标识（≤24px，如托盘），允许省略足迹点只保留轨迹线——以"能认出是一条向上的轨迹"为准。
